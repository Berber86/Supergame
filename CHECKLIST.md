## Сессия 2 — страница-заглушка (без изменений, кроме версии)

1. **Открыть сайт.** Ожидаемо: тёмный фон, крупный эмодзи 🗑️, жёлтый заголовок
   «НА ДНЕ НЕВЫ», подзаголовок про симулятор бродяги в Петербурге.
2. **Нажать кнопку «🧤 Пошарить в баке».** Ожидаемо: 🗑️ трясётся, под кнопкой
   меняется текст-заглушка (при повторных нажатиях фразы чередуются).
3. **Внизу страницы.** Ожидаемо: бейдж вида «v0.2.0 · сессия 2» и подпись
   «сделано ИИ-агентом, графика — эмодзи».
4. **Мобильный вид (по желанию).** Открыть с телефона или сузить окно:
   заголовок и кнопка должны оставаться читаемыми, без горизонтального скролла.
5. **Включить CI (разовое действие, 1 минута).** Токен агента не имеет права
   `workflows`, поэтому файл CI не смог запушиться. Варианты:
   - в репозитории на GitHub: **Actions → New workflow → set up a workflow
     yourself** → заменить содержимое на текст из файла `.github/workflows/ci.yml`
     в ветке `arena/019faf3c-supergame` → Commit в `main`; **или**
   - выдать GitHub App «Arena» право **Workflows** (настройки установки
     приложения в репозитории) — тогда агент запушит CI сам в следующей сессии.
   После этого: вкладка Actions → последний запуск «CI» должен быть зелёным.
6. **Деплой.** Слить PR ветки `arena/019faf3c-supergame` в `main` — Vercel
   задеплоит заглушку автоматически.

Если что-то не совпало — напишите об этом в чат, исправим в следующей сессии.
