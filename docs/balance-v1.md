# The Long Line — балансировочный проход v1 (Этап 4)

Дата прогона: 2026-08-02. Это быстрый smoke/playtest, а не финальный баланс Этапа 5.

## Что проверяется автоматически

Запуск:

```bash
npm run test:stage4
```

Сценарий `scripts/stage4-test.ts` проверяет:

- 72 уникальных узла, ровно 9 в каждой из 8 эпох;
- валидность всех статов и всех рёбер дерева, полный путь I → VIII для каждой линии;
- долю `special_ability`: 24/72 (ровно 1/3), все 8 эффектов и минимум два применения каждого типа;
- монотонный рост средних HP/ATK/DEF по формуле эпох;
- 40 процедурных волн: 4–8 врагов, обязательный танк, ролевые лимиты, уникальные проходимые позиции, корректный средний уровень эпохи и элитные волны;
- восемь репрезентативных регулярных боёв I → VIII (смешанный состав проходит не менее 6/8; текущий фиксированный прогон — 8/8);
- фактическое срабатывание всех восьми способностей внутри боевой FSM;
- 40 боёв «моно-линия против сбалансированного отряда» (5 линий × 8 эпох), отсутствие зависаний и линии, выигрывающей во всех эпохах.

Результат контрольного прогона: **44/44 проверок**. Победы моно-линий против смешанного состава (из 8):

| Линия | Победы |
|---|---:|
| Infantry | 0 |
| Ranged | 1 |
| Cavalry | 1 |
| Support | 0 |
| Siege | 3 |

Этот тест намеренно ставит однородный состав в невыгодное положение: смешанный отряд должен быть устойчивее. Важный критерий — ни одна специализация не проходит все эпохи одним и тем же шаблоном.

## Изменения после первого прогона

1. Профиль Siege получил меньше HP/DEF и дальность 1→5 по эпохам. Его ниша — медленный AoE по плотному строю, а не универсальный танк-снайпер.
2. Cavalry получила ниже базовые HP/ATK. Скорость и обход остаются преимуществом, но линия больше не выигрывает почти каждый контрольный матч.
3. После 90 секунд включается overtime: отступление и кайт прекращаются, базовый урон растёт, лечение постепенно ослабевает. Это устраняет тупики «два раненых юнита бегут к разным краям» и «танк + лекарь».
4. Support без боевого союзника переходит к обычной атаке, поэтому финал «лекарь против лекаря» завершается.
5. Враг получает базовый множитель 0,88 как компенсацию игроку за персистентные ранения и идеальную тактическую расстановку ИИ; элита усиливается относительно этого базиса на 15%.

## Ручной плейтест-чеклист

- [ ] Волны 1–4: стартовый смешанный отряд способен победить, рельеф заметно влияет на стрелков.
- [ ] Волна 5: в превью и HUD видна метка **ЭЛИТА**, все враги ощутимо сильнее, но волна не требует единственной обязательной ветки.
- [ ] После нескольких эволюций средняя эпоха врага следует за `worldEpochScore`, а не только за номером волны.
- [ ] Tank держит фронт, Melee/Cavalry добираются до тыла, Ranged выигрывает от холма, Support полезен рядом с боевыми союзниками, Siege наказывает плотную группу.
- [ ] `BonusVsTank` не усиливается против обычной хрупкой цели; `Trap` срабатывает при входе на гекс; `Shield` сначала поглощает урон; турель исчезает по времени.
- [ ] В каждой линии можно последовательно пройти узлы I → VIII; на развилке обе цели доступны.
- [ ] Длинный бой всё равно заканчивается после включения overtime.

## Известные рамки v1

- Контрольный тест оценивает архетипы и отсутствие грубого доминирования, а не точный win rate каждой пары.
- Экономика лечения/эволюции оставлена достаточно щедрой для прохождения прототипа; тонкая настройка цен относится к Этапу 5.
- Способности используют восемь общих реализаций. Числа масштабируются по эпохе, но индивидуальные коэффициенты пока ограничены диапазоном около ±15%.
