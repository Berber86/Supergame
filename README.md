# 静かな庭 · Усадьба Безмятежности

Браузерная дзен-песочница: ландшафтный и интерьерный конструктор восточной усадьбы
в стиле акварелей студии Ghibli. Никакого сюжета, никакого давления, никаких других
игроков — только вы и ваш сад.

**Статус:** прототип, близкий к альфе. Упор сделан на визуал.

---

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Прочие команды:

```bash
npm run build      # проверка типов + сборка в dist/
npm run typecheck  # только tsc
npm run preview    # предпросмотр собранной версии
```

## Что уже работает

### Визуал — всё рисуется кодом, ни одного растрового ассета

- **Акварельная кисть.** Собственный слой рисования (`src/render/paint.ts`):
  многослойные пятна-кляксы с дрожанием контура, тёмная кромка подсохшей краски,
  зернистость пигмента, сужающиеся мазки для стволов и стеблей.
- **Бесшовный ландшафт.** Тайлы заливаются с перекрытием, поверх ложатся крупные
  размывы в режиме `multiply` и редкие солнечные прогалины. Границы разных
  материалов размываются неровными «языками» — строгая сетка не читается.
- **Живая вода.** Сглаженные бухточки и выступы берега вместо прямых рёбер
  тайлов. Сквозь мелководье видны песчаные отмели, камни и водные растения;
  по дну бегут световые узоры. Слои: дно → приглушённые глубиной карпы →
  полупрозрачная поверхность, отражения и рябь. Рыбы обрезаются контуром пруда.
  Отражения — зеркальные изображения настоящих сезонных спрайтов деревьев,
  мостов и камней, с волновым искажением, а не условные штрихи. Используется
  существующий кэш спрайтов без нового полноэкранного буфера. Раздельные пруды
  имеют независимые маски; правки, отмена и загрузка пересобирают геометрию.
  `src/render/waterSurface.ts` — поверхность, `water.ts` — течение, `cascades.ts` — водопады;
  `tools/check-water.ts` проверяет контуры, клиппинг, 108 кадров, карпов и бюджет рендера.
- **Склоны, глубина и погода:** у горного истока короткие неровные гряды вместо
  широких прямоугольных платформ, шаговые камни ведут от веранды к мостам,
  камыш и ирисы оставляют подходы свободными. Локальная карта глубины отделяет
  светлую отмель от глубокой чаши; карпы периодически погружаются и теряют контраст.
  `waterMotion.ts` связывает искажения отражений с течением и настоящими кругами
  от дождя, посадок птиц и прыжков лягушек. Спокойная вода остаётся почти зеркальной.
  У сильных сливов — небольшая водяная пыль и разорванные пенные следы.
  Дневная дымка слабее, рассвет и погодный туман сохранены; телефон начинает
  ближе к мостам, с запасом для панели инструментов. Проверка: `tools/check-garden-polish.ts`.
- **Горный исток:** начальная карта строит одно связное русло от северной
  границы до озера, без сухих перегородок между прудами. Оба моста пересекают
  узкие участки воды и опираются на сухие берега одинаковой высоты; декор не
  перекрывает русло. Изменён шаблон новой усадьбы, не сохранённые сады игрока.
- **Отражения:** мост отражает высоту своих досок и перил, сохраняя направление
  настила в изометрии. У других предметов учитывается высота основания над водой
  и актуальный рост. Отражаются также кусты, фонари, цветы и декор. Живность
  использует общие с основной сценой позы, высоту полёта, взмахи и условия
  видимости, без отражения наземной тени. Все отражения обрезаются контуром
  конкретного водоёма, включая сухие острова; рыбы остаются под поверхностью.
  `tools/check-spring-reflections.ts` проверяет настоящий шаблон, опоры мостов,
  геометрию отражения и пиксели птицы, бабочки и стрекозы; `--preview` создаёт PNG.
- **Мосты и каскады:** доски, несущая арка, стойки и перила моста используют одну
  изометрическую кривую; мосты не отражаются и не меняют длину случайно по сиду.
  Каскады объединяют клеточные грани в скалистые кромки, состыкованные с верхним
  и нижним зеркалом воды. Разные по ширине потоки, мелкие брызги и открытые
  завихрения заменяют одинаковые пенные диски. Камень у возвышенной воды
  рисуется валунами, не дорожными плитами. Старые сохранения не переписываются.
  `tools/check-structures.ts` проверяет повороты, сиды, старую раскладку каскада,
  стыки воды, историю и загрузку; `--preview` сохраняет игнорируемые PNG из Scene,
  включая кадр шириной 430 px. Это офлайн-рендеры, не замеры на телефоне.
- **Стволы и ветви прежних восьми видов.** У сакуры, клёна, гинкго, ивы,
  хурмы и сосны — изогнутая ось ствола, расширение у корней, плавное сужение
  древесины и бороздки коры внутри силуэта. Скелетные ветви выходят из разных
  точек настоящей оси, а не из одного узла над прямым столбом; тонкие развилки
  соединены с родительскими ветвями. Гинкго растёт вертикальнее, ива даёт
  свисающие побеги, сосна — изогнутые ярусные ветви. Дупла следуют стволу,
  гнёзда опираются на ветвь. У бамбука кольца и боковые побеги привязаны к
  изгибу стебля; глициния обвивает прямые деревянные опоры живыми лианами.
  Геометрия `render/treeWood.ts` зависит от вида, сида и размера, не от месяца;
  точки листвы, годовые процессы и сохранения сохранены. Новые плодовые
  деревья не изменены. Проверка всех восьми видов, нескольких сидов, размеров
  и сезонов: `node --max-old-space-size=192 --import tsx tools/check-tree-wood.ts --preview`.
- **Узнаваемые сосны.** Крона больше не состоит из прозрачных овалов:
  плоские пучки длинной хвои имеют рваный игольчатый край, между ярусами
  видны соединённые со стволом ветви. Чешуйчатая кора, отдельные шишки,
  разное число и длина ветвей зависят от сида. **Пять выраженных форм**:
  приземистая, стройная высокая, склонённая ветром, зонтичная и раздвоенная.
  Высота взрослых сосен различается более чем вдвое; меняются также ширина,
  наклон и изгиб ствола, высота начала кроны, расположение и густота ярусов.
  У раздвоенной формы второй ствол выходит из настоящей развилки.
  Облик выводится из прежнего сида: при загрузке не перетасовывается,
  позиции деревьев и формат сохранения не меняются. Рост, постепенный снег
  и общий ветер сохранены; точка изгиба на ветру учитывает высоту конкретной
  сосны, детали запекаются в прежний ограниченный кэш.
  `tools/check-pine.ts --preview` проверяет 512 сидов, все пять форм, крайние
  размеры, рост, сезоны, сохранения и границы спрайтов; сохраняет офлайн-пример.
  `--before` сохраняет исходное сравнение.
- **Разные характеры лиственных деревьев.** У клёна, сакуры, гинкго, ивы и хурмы
  четыре устойчивые формы: раскидистая, стройная, низкая и наклонённая.
  Внутри формы сид меняет высоту, ширину и глубину кроны, толщину и изгиб
  ствола, число ветвей и места крепления листвы. Высокий гинкго сохраняет
  сужающуюся верхушку, у остальных стройных форм крона более овальная;
  ивы отличаются также длиной и расположением свисающих побегов.
  `world/treeHabits.ts` задаёт постоянный облик, `render/treeGeometry.ts` —
  общий скелет и точки листвы. Цветы, плоды, снег и опад остаются на своих
  ветвях; листовая плотность, тени, влажность почвы и ветер учитывают форму.
  Предметы и формат сохранения прежние. `tools/check-tree-habits.ts --preview`
  проверяет 970 сидов, все формы, времена года, рост и границы кэша.
- **Непрерывный год растений — первый этап.** Кроны сакуры, клёна, гинкго,
  ивы, хурмы и глицинии развиваются по непрерывным кривым: почки → небольшие
  молодые листья → плотная летняя листва → неодновременная окраска участков →
  оголение ветвей. Это не двенадцать месячных картинок: скелет и точки крепления
  листвы постоянны, меняются размер, заполнение и цвет отдельных групп.
  У видов разные сроки, у экземпляров — постоянный сдвиг примерно до шести дней.
  Сосна и бамбук сохраняют зелень, её зимний тон приходит постепенно; оттенки
  вечнозелёных кустов также плавные. Розовая крона сакуры появляется раньше листьев,
  грозди глицинии развиваются отдельно от её зелени; ночное закрытие цветов сохранено.
  `annualPhase` в `core/clock.ts` задаёт опорные даты 15 января/апреля/июля/октября,
  учитывая настоящий календарь и високосный год. `world/phenology.ts` — процессы,
  `render/crownGeometry.ts` — неизменная геометрия ветвей. Возраст посадок и сохранения
  не меняются; возвращение к дате не требует проигрывать пропущенные дни.
  Кэш спрайтов **и их границ** учитывает годовую ревизию примерно раз в 17 часов,
  со сдвигом по сиду, а не на каждом кадре. У ревизии фиксированная расчётная дата,
  поэтому история просмотра и перевод часов не меняют её геометрию. Суточное
  раскрытие цветов использует настоящее время. Пределы — 420 спрайтов и 600 замеров;
  предметы без годовых изменений (например, мебель) не получают лишний годовой ключ.
  `npx tsx tools/check-phenology.ts` проверяет годовой проход, границы месяцев/года,
  виды, сиды, кэши и отсутствие обрезанных крон; создаёт `preview-annual-crowns.png`.
  `--preview` дополнительно сохраняет кадры настоящего сада, включая ширину 430 px.
  В мастерской времени (T / нажатие на часы) есть пресеты всех 12 месяцев:
  переход на 15-е число с сохранением выбранного часа. Четыре сезонные кнопки
  ведут к апрелю, июлю, октябрю и январю. Панель показывает фактическую дату
  и текущий месяц при ускорении; прежнего скачка назад через 40 дней больше нет.
  Старые настройки с одним сезоном автоматически совместимы с выбором месяца;
  режим «стоп» сохраняется после перезагрузки. Проверка: `tools/check-time-control.ts`.
- **Непрерывный год — второй этап.** Ландыши, ирисы, лотосы, азалии, камелии
  и дикорастущие цветы получили собственные периоды распускания и увядания.
  Размер и присутствие венчиков меняются отдельно от суточного раскрытия:
  ночью цветы по-прежнему закрыты, фонари не пробуждают их. Водяные растения
  постепенно уходят в покой и вновь отращивают листья.
  Опад привязан к виду, сиду, размеру и фактически потерянной площади кроны:
  под листопадными деревьями осенью появляется плотный неровный ковёр, а не
  несколько случайных листочков. В марте остаётся около половины прошлогодней
  листвы, серо-бурой и сморщенной; в апреле слой заметно реже, к июню исчезает.
  Свежие весенние лепестки сакуры — отдельный слой, они не перекрашивают старые
  листья. Под снегом опад постепенно скрывается. Ковёр виден и при отдалении
  камеры; прежний предел — 400 небольших кэшированных пятен — сохранён.
  Проверка годового цикла и превью: `tools/check-litter.ts --preview`.
  Снег на земле растёт из постоянных нерегулярных пятен, с мягкими краями;
  он не возникает сплошным белым слоем 1 декабря и не исчезает 1 марта.
  Скаты, ветви и камни получают постепенно растущие снежные шапки. У разных
  крыш разная удерживающая способность, без трёхдневной перетасовки рисунка.
  Прибрежный лёд расширяется и отступает на постоянных местах; русла и
  водопады остаются открыты. Сосульки плавно растут и тают под выбранными свесами.
  Палитра земли и воды также проходит через четыре среднесезонных ориентира
  непрерывно, не только в последние дни сезона.
  `world/annualEnvironment.ts` задаёт независимые кривые. Это календарная
  модель, **не накопительная симуляция температуры и осадков**: изменение даты
  сразу показывает её состояние, даже после загрузки или перемотки назад.
  Кэши земли, напочвенных пятен, крыш, спрайтов и их границ учитывают годовой
  прогресс и остаются ограниченными. Сохранённый сад не изменяется.
  Проверка: `npx tsx tools/check-annual-environment.ts --preview`; PNG первых
  снегов, зимы, оттепели, весны, лета и опада сохраняются как игнорируемые артефакты.
- **Непрерывный год — третий этап.** `world/canopy.ts` выводит оптическую плотность
  из площади, раскрытия и удержания тех же групп листвы, которые рисуют крону.
  Цветущая сакура даёт укрытие ещё до листьев; вечнозелёные не теряют его зимой.
  При листопаде отбрасываемая тень плавно сужается и бледнеет, но контактная
  тень ствола сохраняется. Это стилизованная мягкая тень, не трассировка ветвей.
  Отражения используют тот же годовой спрайт и ту же фазу покачивания, что дерево
  на берегу. Их не затемняют повторным коэффициентом листвы: голые ветви и ствол
  продолжают отражаться, не исчезая вместе с листьями.
  Остаточная влажность, лужицы и мокрые материалы учитывают текущую крону:
  при одинаковом недавнем дожде оголённое место высыхает быстрее, густая крона
  удерживает сырость дольше. Затенение зданий остаётся постоянным. Мох и грибы
  постепенно меняют выраженность по этому микроклимату, без пересоздания пятен.
  Фонари не меняют влажность или годовую фазу и не открывают ночные цветы.
  Модель не накапливает отдельную историю воды в каждой клетке; существующие
  ограничения по снегу и замерзанию применяются плавно, а не по названию сезона.
  Пространственные связи строятся при правках сада; годовой скалярный слой
  хранит только текущее состояние. Плотности и размеры теней ограничены
  600 записями каждый, кэши спрайтов/границ по-прежнему 420/600.
  Проверка: `npx tsx tools/check-canopy-environment.ts --preview` — годовые
  кривые, реальные тени/отражения, влажность, перемотка, кэши, перенос/отмена,
  загрузка и неизменность сохранения; четыре PNG разных стадий года.
- **Согласованный экологический год (исправление ранней весны).**
  `world/ecology.ts` задаёт общий непрерывный ритм умеренного сада — это
  художественная климатическая модель, не прогноз по местоположению игрока.
  В марте земля остаётся серо-охристой с приглушённым оливковым мхом;
  прошлогодняя трава зеленеет к апрелю, а не вместе с надписью «весна» 1 марта.
  Сакура, азалии, травяные цветы, папоротники и водные растения просыпаются
  в свои сроки; камелия сохраняет собственное зимнее цветение.
  Бабочки, пчёлы, стрекозы, мотыльки и светлячки, а также лягушки, черепахи
  и ёжики получают разные периоды активности. Учитываются день/ночь, дождь,
  снег и ветер. Улей — дом, не цветок: пчёлы выбирают доступные цветущие
  растения, не собирают пыльцу с папоротника или отцветшего стебля.
  При перемотке летние насекомые не остаются в марте ни в саду, ни в отражениях;
  уменьшающиеся популяции уходят, а не ждут полного выключения сезона.
  Летящие лепестки и листья приходят только от реально осыпающихся деревьев.
  Убраны дублирующие фоновые светлячки и снегопад «просто потому, что на земле снег».
  Шорох листвы учитывает реальные кроны, звуки насекомых — тёплую часть года.
  Автоматическая погода, холодная дымка и цветокоррекция меняются плавно;
  мокрые материалы подавляются снегом и замерзанием, не 1 декабря.
  Ручные погодные эффекты по-прежнему доступны. HUD показывает месяц и стадию
  пробуждения сада вместо постоянных мартовских «лепестков на воде».
  Иконки и их границы обновляются внутри сезона, с ограничением по 300 записей.
  Проверка: `npx tsx tools/check-ecological-year.ts --preview` — начало/середина/
  конец марта, апрель, май, лето, осень; реальные агенты, отражения, нектар,
  частицы, погода и кэши. PNG создаются как игнорируемые артефакты.
- **Текстура бумаги.** Процедурная рисовая бумага с волокнами накладывается на
  кадр через `overlay` + `soft-light`, плюс виньетка по краям листа.
- **Усадьба как постройка** (`src/render/building.ts`): дальние стены с решёткой
  сёдзи с бумажными волокнами и деревянным цоколем. Скаты сходятся на общем
  коньке вдоль длинной оси дома; у кровли черепичные ряды, толстые свесы,
  торцы стропил, балки и стойки с подкосами. Тень под крышей лежит **под**
  мебелью и исчезает вместе с кровлей. Детали крыши кэшируются в одном
  ограниченном буфере, не пересчитываются на каждом кадре.
- **Интерьер в едином масштабе** (`src/render/sprites/furniture.ts`): стол с чайным
  подносом, мягкие подушки, очаг, футон, ширмы, сёдзи и фусума, ниша со свитком,
  бонсай. Добавлены низкий шкаф тансу, растение в керамике, котацу с одеялом,
  книжная полка и скамья для веранды. Повороты идут
  по осям пола; случайное зеркалирование и масштабирование мебели отключены.
  В новых садах — готовые зоны чая, отдыха и очага. Старые предметы сохраняют
  позиции, сиды и отпечатки; сохранённые комнаты **не обставляются автоматически**.
  В вольных садах с домом комплект доступен сразу; прогресс растущего сада сохранён.
  `npx tsx tools/check-house.ts --preview` проверяет 14 предметов в четырёх
  поворотах, кэш, геометрию крыши, сохранение и историю; создаёт дневные/ночные
  PNG с крышей и без, включая портрет 430×800 (не аппаратный тест телефона).
- **Малые дома и зимняя кровля:** чайный домик, дом 3×2, сарай и беседка
  построены в координатах своих реальных отпечатков. Проёмы, решётки окон,
  норэн, деревянные цоколи, солома и торцы стропил поворачиваются вместе с домом.
  На главном доме и малых постройках бывают чистые крыши, частичные наносы
  или плотный снег: удержание определяется постоянным сидом здания, а площадь
  покрова плавно меняется по календарю. Узор не мерцает, сохраняется после загрузки,
  обрезается скатами и учитывает ночь. Накопление осадков физически не моделируется.
  Кэши рисунка **и границ** учитывают смену снежного состояния.
  `npx tsx tools/check-roof-snow.ts --preview` проверяет сезон, повороты,
  сохранение, маски и обновление кэша; создаёт зимние дневные/ночные PNG.
  Каталог готовых вольных садов с домом доступен без повторного рисования пола,
  без добавления незаслуженных вех в сохранение и без изменения режима роста.
- **Сад после дождя:** дождь оставляет остаточную влагу, а не только исчезающие
  частицы. Открытые камни, мосты и доски темнеют и получают сдержанный блеск;
  их отражения используют то же мокрое состояние. В низинах и редких небольших
  углублениях возникают прозрачные лужицы с отражением цвета неба, которые
  уменьшаются при высыхании. Нет луж на стекающих уступах, в прудах, на деревянных
  полах и под крышами. С карнизов главного дома и четырёх малых построек ещё
  некоторое время падают редкие капли; они учитывают поворот и видимость кровли.
  В ясный день земля сохнет примерно три минуты после прекращения дождя,
  ночью/при облачности — медленнее; в тени видимая влага задерживается дольше.
  Карнизы освобождаются от воды раньше земли. Зимой эффект отключён, снег не заменяется
  лужами. Влага, как и погода, хранится в состоянии текущей сессии, не меняет усадьбу
  и формат сохранений. До 24 лужиц; влажная земля рисуется пакетами, без нового
  полноэкранного холста. Капли отключаются вместе с частицами, мелкие круги — на
  дальнем плане. `npx tsx tools/check-after-rain.ts --preview` проверяет переходы
  дождь→ясно→сухо, тень/укрытия, маски, кэши, отражения материалов через общую
  атмосферу, правки/отмену, вращение карнизов и нативный бюджет с растеризацией.

- **Живой напочвенный слой:** вместо повторяющейся россыпи пятен на каждом тайле —
  редкие сообщества травы, мха и полевых цветов, небольшие оголённые участки,
  корни у стволов, хвоя под соснами и характерная листва под клёнами/гинкго/другими
  деревьями. Грибы требуют сырой тени: учитываются кроны, мох и близкая вода;
  полевые цветы выбирают открытые дневному солнцу места, не свет фонаря.
  Это декоративный слой, не новые предметы: он не занимает строительные места,
  не меняет посадки, сохраняет свободное место около садовых цветов, не попадает
  на дорожки, полы и воду. Размещение детерминировано и обновляется при правках/отмене.
  Зимой слой скрыт под снегом. При отдалении исчезают цветки, грибы и отдельные листья,
  затем мелкая трава. Не более 400 групп и одного актуального набора маленьких
  растровых отпечатков на сад (до 8,6 МиБ); за кадром детали не рисуются.
- **Ночью все цветы закрываются:** ландыши, ирисы, лотосы, цветки сакуры,
  азалии, глицинии, камелии и дикорастущие цветы складываются в бутоны к ночи
  и раскрываются утром. Это визуальный суточный цикл, включая условное поведение
  видов, которые в природе так не делают. Фонари не будят цветы; сезонность
  и размещение игрока сохранены. Фаза раскрытия входит в кэши спрайтов и их границ,
  в том числе для отражений и локальной подсветки.
  `npx tsx tools/check-ground-life.ts --preview` проверяет экологию, ночные бутоны,
  кэш, отмену, загрузку, маски, уровни детализации и нативный бюджет с растеризацией;
  создаёт дневное/ночное/узкое превью и сравнение форм цветов при одинаковой палитре.

- **Локальный свет:** ночью и в сумерках окна, три вида фонарей, жаровня и очаг
  подсвечивают ближайшие пол, стены, мебель и растения. Материалы сохраняют рисунок
  и собственный цвет; свет затухает с расстоянием, учитывает перегородки и высоту земли.
  На воде — слабое тёплое пятно и движущиеся разорванные блики внутри контура пруда.
  Крыша перекрывает интерьерную подсветку. Перенос/удаление источника и отмена действий
  сразу обновляют свет; формат сохранений не менялся.
  До 48 источников и двух вкладов на приёмник; две переиспользуемые маски для крупных
  спрайтов (256×256 и 512×512, вместе 1,25 МиБ), мелкие материалы без промежуточного холста;
  один дополнительный освещённый вариант материала в общем ограниченном кэше, а не
  варианты на каждый фонарь и кадр. `npx tsx tools/check-local-light.ts --preview`
  проверяет маски, препятствия, повороты, сохранения, кэш и нативный бюджет;
  создаёт ночные/сумеречные PNG и узкое превью (не замер на физическом телефоне).

- **Зимние исправления:** снежная подложка заполняет и клетки под будущей водой —
  затем единый контур пруда вырезает плавный берег, без квадратных бесснежных пятен.
  Лотос и кувшинки зимой переходят в покой (сухой стебель/остатки листа, без цветения).
  `winterIce.ts` добавляет случайный тонкий прибрежный лёд с открытой серединой;
  текущие участки и водопады не замерзают. Под снежными свесами иногда появляются
  сосульки. Места постоянны, размеры меняются плавно при замерзании и оттаивании,
  в том числе на границе календарной зимы.
  Книжный шкаф собран из тонких полок, книги не закрыты плитами. Исходная сосна
  у комнаты перенесена за веранду; узкая миграция узнаваемого стартового сада
  сохраняет ID/возраст/сид дерева и не переставляет произвольные посадки игрока.
  Новые деревья нельзя сажать на татами и веранду (бонсай разрешён).
  Проверки и портретные PNG: `npx tsx tools/check-winter-fixes.ts --preview`.
- **Свет.** Солнце ходит по небу и по высоте, и его правда видно в кадре —
  утром диск слева, вечером закатный справа, над краем острова. Тени бегут
  от него: утром вправо, к полудню собираются под объект, к закату тянутся
  влево длинной цепочкой пятен. Кроны лепятся по солнцу — светлая сторона,
  глубокая тыльная, золотой кант в свой час. Золотой час льёт в кадр
  закатное пламя со стороны светила, ночь красит сцену в индиго, а в небе
  плывёт луна.
- **Глубина.** Дальний край усадьбы тонет в бумажной пелене: воздушная
  перспектива ложится по изометрической оси глубины, утром она прохладная,
  к закату теплеет. Грейдинг кадра направленный: тёплое плечо со стороны
  солнца, прохладное — со стороны тени.
- **Погода и частицы.** Лепестки сакуры весной, палые листья осенью, снег зимой,
  светлячки тёплыми ночами, утренняя дымка, мягкие лучи сквозь листву.
- **Стартовая страница — свиток на стене.** Тёмная комната, лист на шнуре,
  энсо и каллиграфия; тушь ложится на глазах, свет идёт по настоящему часу
  игрока, вход — шаг через порог (`src/ui/startArt.ts`, `src/ui/startScreen.ts`).

### Энциклопедия животных

- **Вход:** кнопка с открытой книгой справа и строка в свитке помощи.
- **23 страницы, 133 режима просмотра:** все звери, пять видов маленьких птиц,
  цапля, сова, кои, оба окраса лягушек, обе стрекозы и прочие насекомые.
  Страницы доступны сразу, независимо от встреч, сезона и построек.
- **Живые зарисовки:** те же процедурные модели, что в саду, с выбором состояния,
  окраса (где есть), поворотом, паузой, перемоткой и скоростями ¼×–2×.
  «Все подряд» последовательно показывает все состояния выбранного животного.
- **Бережный просмотр:** поиск, мобильная раскладка, закрытие через Esc,
  удержание фокуса внутри книги и возврат к кнопке входа. При reduced motion
  воспроизведение запускается вручную. Закрытая книга не запускает rAF;
  экземпляры животных в ней не меняют мир и сохранения.
- **Новые олень и черепаха:** суставные ноги и шаг по пройденному расстоянию,
  плавное опускание головы оленя, объёмные щитки панциря, втягивание лап и
  головы черепахи, отдельные гребки и короткие заплывы с возвращением на берег.
- **Новые ёжик, белка и цапля:** плотная направленная шубка и плавное
  сворачивание ёжика; пушистый хвост, приземлённая стойка, прыжки и закапывание
  ореха у белки; суставные ноги, складная S-образная шея, перьевые крылья,
  плавная посадка и синхронный бросок цапли. Все 19 состояний доступны в книге;
  в полёте камера отъезжает, чтобы крылья помещались на странице.
- Рендер этих трёх жителей — `src/render/forestAnimals.ts` и `src/render/heron.ts`,
  общие позы и скорости — `src/world/wildlifeMotion.ts`.
  `tools/check-forest-animals.ts` проверяет поведение, таймеры действий,
  независимость походки от FPS и 456 дневных/ночных кадров.
- **Остальные жители тоже обновлены:** коты с четырьмя окрасами, плавными
  переходами между шестью позами и отдельными лапами; мыши с быстрым шагом,
  ушками и усами; сова с лицевыми дисками, маховыми перьями и плавным подъёмом
  после охоты. Полосы котов привязаны к тем же кривым спины и живота, что и
  силуэт: следуют сидячей позе, умыванию и плавным переходам, сужаются к концам
  и не пересекают светлую грудку. `tools/check-cat-coat.ts --preview` проверяет
  180 переходов поз и все окрасы; сад и энциклопедия используют одну модель.
  У пяти маленьких птиц свои пропорции, хвосты, шапочки и полосы
  на крыльях; клевание, питьё и купание не повторяют неподвижную посадку.
- **Пруд и насекомые:** у кои двулопастный хвост, плавники, чешуя и жабры;
  у лягушек суставные задние лапы, перепонки и горловой мешок. У бабочек и
  мотыльков узорчатые крылья, у стрекоз — жилки и разная посадка двух видов;
  у пчёл видна пыльца, у светлячков — сам жук между вспышками. Пчёлы собирают

- Эти модели находятся в `src/render/{cats,smallBirds,nocturnalAnimals,pondAnimals,insects}.ts`;

  одни и те же функции. `tools/check-remaining-animals.ts` проверяет переходы,
  движение и 3808 кадров: 17 страниц / 93 состояния, все доступные в книге
  окрасы, день/ночь и оба направления. Проверка автоматически входит в `npm test`.
- Реестр страниц — `src/ui/animalGuideData.ts`, окно — `src/ui/animalGuide.ts`,
  новые модели — `src/render/deerTurtle.ts`. `tools/check-animal-guide.ts`

### Школа тишины — симулятор обучения дзену и медитации

- **Восемь практик** (`src/zen/content.ts`): три вдоха, счёт дыхания до десяти,
  дыхание кругом, просто сидение, медленный шаг кинхин, слушание сада,
  доброта метта и коан. Длительности — настоящие минуты.
- **Десять уроков курса** тихими текстами: поза, дыхание, мысль, энсо, шаг,
  звук, непостоянство, коан, доброта, обычное. Каждый урок ведёт в свою
  практику и оставляет «что заметить». Следующий урок предлагается, но не
  запирает свободное сидение.
- **Мягкий таймер.** Отсчёт есть, провала нет: ни очков, ни серий, ни оценок.
  Встать можно в любую секунду, и досрочное сидение записывается как
  состоявшееся — четыре минуты это четыре минуты.
- **Сеанс ведёт звук и круг.** Поющая чаша на входе и конце, деревянный хан
  между кругами, шумовой вдох и выдох; сад на время сеанса слышен издали.
  Круг дыхания, дорожка шагов, круги по воде или неподвижный энсо рисуются
  по режиму практики (`src/ui/practicePanel.ts`).
- **Тихая память** (`usadba.practice.v1`): какие уроки прожиты, сколько
  сеансов, сколько всего минут тишины. Отдельным ключом, вне сохранений
  усадеб: медитирует человек, а не сад.
- **Вход без новых клавиш и без девятой кнопки:** строка «сесть в тишине»
  приходит в созерцании, когда интерфейс уже растворился, и строкой в
  свитке помощи. Пока лист практики открыт, сцена не рисуется вовсе.

### Камень и дорожки

Валуны, триады, шаговые и водяные камни получили непрозрачный объём,
асимметричные грани, минеральное зерно, трещины и контакт с землёй.
Поворот меняет геометрию, сохраняя характер породы. Плиты дорожек больше
не сливаются в белую ленту: видны промежутки, толщина и подогнанная укладка
на площадках; перекрёстки остаются дорожками, а не ромбами.

После дождя верх сохнет раньше щелей, в тени сырость держится дольше;
места мха зависят от среды. Камень в воде имеет влажную ватерлинию,
отдельные живые круги и отражение. Ящерицы опираются на высоту конкретного
камня, в том числе после его поворота. Старые сады обновляются без миграции
и пересадки предметов. Кэши и три графических режима сохранены.

[Устройство, ограничения симуляции и проверки](docs/stone-material.md).

### Общий ветер

**«Умный ветер» — отдельный переключатель в настройках, по умолчанию выключен**
(в том числе при загрузке прежних настроек без этого поля). Выбор сохраняется
для всех усадеб и применяется сразу. Без него остаётся простое лёгкое
покачивание; фронты, задержанные поля и их пространственные выборки не считаются.
Ни качество графики, ни «Плавные движения» сами не включают умный ветер.
Ниже описан включённый режим.

- Порыв проходит по саду направленным фронтом; начало рассчитывается от
  наветренного края для всех направлений, включая отрицательные координатные
  проекции. Между фронтами есть настоящие затишья. Осень, зима и дождь
  усиливают давление плавно, не переключают месячные картинки.
- Трава откликается быстро, бамбук — с короткой упругой реакцией, кроны
  тяжелее и медленнее. У ивы сильнее движение, у сосны и плотного юдзу — слабее.
  Это художественные параметры материалов, не ботаническая физическая модель.
- У деревьев больше нет сдвига всего спрайта вместе с корнями. На балансе и
  максимуме нижняя древесина остаётся неподвижной, верх получает наклон от
  того же поля. Лёгкий режим использует один наклонённый от основания рисунок.
  Камни, здания и опоры перголы не раскачиваются.
- Вода, преломление отражений, опадающие листья, бумажный фонарь и фурин
  используют местное направление и силу. Шорох слышен по ветру у камеры,
  звон — по порыву у самого колокольчика с ослаблением по расстоянию.
  Отражения крон и подсветка фонарями повторяют ту же позу растения.
- Кроны **не перерисовываются** на каждом шаге ветра: один/два прохода готовой
  текстуры, без новых ключей в кэше. Поле фронтов не хранит историю лет и не
  попадает в сохранение. Время ветра не зависит от ускоренного календаря.
  «Плавные движения» отключают наклоны; настройка частиц отдельно управляет опадом.
- `tools/check-wind.ts`: прохождение всех углов сада, задержки, затишья,
  30/60/144 Гц, неподвижное основание, отражения, листья, кэши и длительный
  расчёт. `--preview` сохраняет кадр и последовательность во временный
  `/home/user/.cache/wind-frames`; демонстрация ускорена в четыре раза.
  `tools/bench-graphics.ts --wind-peak` замеряет сцену на сильном фронте.

### Графика и экономия ресурсов

В настройках «Как смотреть» есть три режима: **Лёгкая** (до 30 кадров/с,
DPR до 1), **Баланс** (до 60, DPR до 1,5; по умолчанию) и **Максимум**
(до 60, DPR до 2). Меняются разрешение холста, тонкость отражений,
декоративные детали и постобработка, но не жизнь сада, часы или сохранения.
Частицы и плавные движения остаются отдельными настройками. Переключение
не требует перезагрузки; кнопки доступны с клавиатуры.

Убраны скрытая работа выключенной погоды, лишний проход бумажной текстуры,
лишние расчёты календаря и отрисовка воды за кадром. Исправлены снимки на
HiDPI и исчезновение крон у края экрана при приближении. До выбора сада
нет ни симуляции, ни скрытых прогревочных кадров. После входа скорость
симуляции одинакова во всех графических режимах;
ограничитель проверен на 60/90/120/144 Гц.

Подробности, ограничения и сравнительные **программные**, не телефонные,
замеры: [docs/graphics-performance.md](docs/graphics-performance.md).
Проверка: `node --import tsx tools/check-graphics.ts --preview`.

### Бережное прореживание перегруженного сада

Свободная посадка остаётся свободной. При **загрузке выбранного сада**
(в том числе при переключении усадьбы и приёме файла) проверяются мягкие
пороги из `world/landscapeDensity.ts`:

| Группа                                                               | Порог |
| -------------------------------------------------------------------- | ----: |
| Деревья, в том числе бамбук и плодовые                               |    80 |
| Кусты                                                                |    80 |
| Цветы, трава, мох и водные растения                                  |   200 |
| Кормушки, поилки, ульи, бельчатники, брёвна для черепах и сиси-одоси |    24 |
| Камни и галька                                                       |   100 |
| Наружные фонари и жаровни                                            |    48 |

- Пока число предметов группы **не превышает** порог, ничего не меняется.
  Постройки, мосты, шаговые дорожки, вся мебель/декор дома, миски и подушки,
  коты и карпы не учитываются и не удаляются.
- В превысившей порог группе ищутся только копии **одного вида** не дальше
  двух клеток от старейшей посадки. Поворот вращаемых предметов и
  разные уровни/вода/полы разделяют группы. Сид не сравнивается: повторный
  клик всегда выдаёт новый сид. Соседние скопления не объединяются цепочкой
  вдоль целой клумбы.
- Старейшая посадка на месте остаётся. Из остальных копий убираются две трети,
  с округлением вверх: 20 предметов в одной точке превращаются в 7, три —
  в одну. Результат детерминирован; координаты, возраст, сид, ID и порядок
  оставшихся предметов не меняются. Номера удалённых предметов не переиспользуются.
- За загрузку выполняется **один проход**, не цикл до достижения порога.
  Если густой сад состоит из отдельных посадок без дублей, его не обрезают
  произвольно. Действия растущего сада, его размер, открытия и летопись
  не сбрасываются и не штрафуются. Во время игры и автосохранений чистка
  не запускается; сады, оставшиеся в стартовом списке, вообще не трогаются.
- До изменения записывается отдельная копия `usadba.garden.<id>.before-thinning`.
  Обычные автосохранения её не перетирают; она обновляется только перед
  следующим прореживанием этого сада. Кнопка в уведомлении и в «Усадьбах»
  выгружает эту копию файлом. При удалении самой усадьбы убирается и копия.
  Если запись копии или результата невозможна, **сад открывается без удаления**
  с предупреждением и предложением выгрузить его.
- Исходник проверяется обычным парсером целиком. Прореживание не превращает
  повреждённый файл в «валидный» путём выбрасывания плохих объектов. Резервные
  и временные сохранения восстанавливаются прежним способом; копия до
  прореживания служит дополнительным последним вариантом восстановления.
- Соседи ищутся пространственным индексом якорей, а не попарным сравнением
  всех предметов. `tools/check-landscape-density.ts` проверяет границы порогов,
  защищённые предметы, плотные/разнесённые посадки, все пути загрузки, отказы
  хранилища и выгрузку копии, включая 50 тысяч растений в одной точке.

### Осенние уточнения: ива, опад и лягушки

- У всех четырёх форм ивы длинные свисающие побеги с узкими листьями.
  Древесина и листва следуют одним кривым; концы разной длины остаются
  над землёй. Геометрия по-прежнему берётся из сида, рисунок — из кэша,
  а ветер и отражения используют тот же силуэт.
- Начало пожелтения даёт небольшой ранний опад: 20 сентября под клёном
  и сакурой есть отдельные листья, но не ноябрьский ковёр. Ива и гинкго
  сбрасывают их позже. Осенний опад связан с утраченной площадью кроны и зависит от
  даты/породы/сида, а не от времени открытой вкладки. В марте ещё остаются
  прошлогодние бурые листья; к июню они исчезают. Хвоя сохраняет прежний
  круглогодичный цикл. При отдалении остаются редкие различимые отметки,
  без дополнительной симуляции частиц или накопления объектов.
- Цель прыжка лягушки выбирается от её текущего положения на берегу
  родного пруда, не от центра водоёма. Прыжок — не дальше 1,1 клетки,
  занимает как минимум 1,4 секунды и удлиняется с расстоянием. Между
  прыжками остаются паузы; нет перелётов между поилками или скачков через
  перепад рельефа. Проверка `tools/check-frog-motion.ts` охватывает настоящую
  симуляцию, траектории и скорость на 30/60/144 Гц, испуг и приземление.

### Плодовый сад

- **Умэ:** искривлённый старый ствол, бело-розовые цветы на голых ветвях
  в конце зимы, небольшие зеленовато-жёлтые плоды и фруктопад в начале лета.
- **Наши:** широкая горизонтальная крона, белые весенние цветы, круглые
  золотистые груши с крапинками к концу лета и осени.
- **Персик:** развилка чашей, узкие листья, розовое весеннее цветение,
  румяные летние плоды с бороздкой. **Юдзу:** приземистая вечнозелёная
  крона с тёмными глянцевыми листьями; фактурные жёлтые плоды держатся
  с осени через Новый год, видны под снежными шапочками.
- Цветение, рост, налив, окраска, удержание и опадение плодов — непрерывные
  кривые с индивидуальными сроками дерева и отдельных ветвей, не месячные
  картинки. Цветы закрываются ночью; после цветения остаются светлые лепестки.
  Нектар зовёт насекомых только в их активное время, падалица персика и наши
  привлекает воробьёв; деревья участвуют в общей модели тени и среды обитания.
- Фруктопад — редкая живая анимация с ускорением и коротким отскоком,
  вне кэша спрайтов, максимум один плод на видимое дерево одновременно.
  Юдзу роняет плоды позже и реже. Отключение частиц отключает анимацию,
  но не сезонное созревание и падалицу. Падения не рисуются над водой,
  в помещении, на перепадах высоты или за границей открытого сада.
- Под каждым деревом не более семи фруктовых отметок: они темнеют,
  сморщиваются и исчезают, обрезаются общей маской сухой земли/берега.
  Общий предел наземных штампов остаётся **400**. Урожаи, упавшие плоды
  и история лет не накапливаются в памяти или сохранениях.
- В свободном саду все четыре вида сразу доступны в деревьях, в том числе
  после загрузки старого сохранения; в растущем саду сохраняется открытие
  через обычный каталог. Формат сохранений не меняется.
- Проверка и изображение: `node --max-old-space-size=192 --import tsx tools/check-orchard.ts --preview`.

### Ящерица — солнечный гость

- Обновлённый японский сцинк: объёмная чешуйчатая спина с продольными полосами,
  щитки на голове, светлое брюшко, глаза с бликом и отдельная нижняя челюсть.
  У четырёх суставных лап по пять тонких пальцев; шаг зависит от пройденного
  расстояния. Длинный сужающийся хвост изгибается вслед за движением, а не
  поворачивается целиком. Дыхание, настороженная стойка, приседание перед
  охотой, моргание, язык и короткий бросок одинаковы в саду и в книге.
  В атласе отдельная страница, **9 состояний** и **4 устойчивых окраса**:
  бронзовый, песочно-бурый, оливково-бурый и молодая полосатая форма с синим хвостом.
- Активность плавно нарастает поздней весной и затихает осенью; дневное окно
  примерно **08–18 часов** с максимумом около 10–16. Дождь, снег и ночь
  отправляют её в укрытие. Это художественная экология сада, не прогноз погоды.
- Интересуют сухие камни вне густой кроны, щели, кусты и травяные края.
  Утром прогревается; в ясный полдень 12–15 ищет ближайшие кусты.
  Перебегает короткими маршрутами, замирает, высматривает и ловит насекомых.
- Может поймать присевшую бабочку, но не преследует улетевшую; максимум две
  такие поимки за визит. Кот замечает ящерицу и подходит, она настораживается
  и удирает. Боится близких птиц, цапли и совы. Уступает камень черепахе и
  другой ящерице. Сцены без крови; обычная мелкая добыча не создаёт новых агентов.
- До **трёх** гостей одновременно. Маршруты не проходят через воду, помещения,
  веранды, перепады уровня и туман неоткрытого сада. С наступлением неактивного
  времени агенты удаляются не позднее пяти секунд обновлений, даже спрятавшиеся.
  Тела и отражения используют общий сезонный фильтр; встреча попадает в летопись.
- **Полевые заметки в энциклопедии:** сезон, дневное окно, пища и условия
  визита; пять акварельных наблюдений с подсказками. Иллюстрации доступны сразу,
  но просмотр книги не выдаёт вех и не меняет сохранение. Рисунки также
  появляются в летописи и уведомлениях. Пять WebP (до 900×600), суммарно ~414 КиБ;
  общая карта иллюстраций — `src/ui/chronicleArt.ts`.
- **Пять событий — пять тихих вех:**

  | Событие         | Веха                | Когда записывается                                                    |
  | --------------- | ------------------- | --------------------------------------------------------------------- |
  | `meet_lizard`   | Солнечный гость     | Первый настоящий визит                                                |
  | `lizard_bask`   | Впитать солнце      | Непрерывный отдых на солнечном камне после подъёма на его поверхность |
  | `lizard_hunt`   | Маленький охотник   | Завершённый бросок с поимкой, включая мелкую наземную добычу          |
  | `cat_lizard`    | Кошачье любопытство | Кот действительно начал подкрадываться к ящерице                      |
  | `lizard_escape` | Быстрее тени        | После опасности ящерица достигла реального укрытия                    |

  События и вехи выдаются один раз. Улетевшая добыча, оборванный маршрут,
  уход на ночь и события за туманом не засчитываются. Старые записи встреч,
  охоты и внимания кота тихо восстанавливают соответствующие вехи при загрузке —
  без повторных уведомлений и без придумывания новых событий. Формат сохранений прежний.

- Проверки: `tools/check-lizard.ts --preview` (в том числе **864 кадра** всех
  окрасов/поз днём и ночью, в обе стороны и на двух размерах экрана),
  `tools/check-lizard-events.ts` (условия событий, миграция, дедупликация,
  сохранение, иллюстрации и DOM), `tools/check-animal-guide.ts` (управление,
  полевые заметки, reduced motion и отсутствие изменений мира).

### Время и мир

- **Вольный сад** живёт по местным часам и календарю игрока.
- **Растущий сад: месяц — 1 реальный час, год — 12 часов, солнечные сутки — 5 часов.**
  Календарь и солнце идут независимо, без случайных отклонений. Каждый следующий
  год тот же месяц начинается на 9 часов 36 минут солнечного времени позже;
  сочетание месячной и солнечной фаз повторяется через **60 реальных часов**
  (5 лет сада и 12 суток). Например, 06:00 → 15:36 → 01:12 → 10:48 → 20:24 → 06:00.
  Февраль и длинные месяцы занимают одинаковый реальный час; развитие растений,
  снега и сезонной активности непрерывное, а не набор месячных картинок.
- **Часы переживают закрытие вкладки.** В сохранении хранится один небольшой
  якорь времени; прошедший срок вычисляется напрямую, без проигрывания пропущенных
  кадров и накопления истории. Старый растущий сад получает якорь при первом
  открытии, новые сады — при создании. Низкий FPS не замедляет календарь и солнце.
- **Мастерская времени (T)** сохраняет ручной выбор всех 12 месяцев, часа и скорости.
  При отключении ручного управления возвращается текущая фаза часов сада;
  открытие растущего сада не наследует старую отладочную скорость.
- **Игровые таймеры не ускорены:** действие по-прежнему начисляется каждые
  10 настоящих минут (до трёх в запасе), реальные отметки посадки не меняются.
  Предметы, как и прежде, сажаются взрослыми.
- **Зимовка без накопления невидимых животных.** Несезонные насекомые, лягушки,
  черепахи и ежи не остаются навсегда в массивах симуляции: обычному уходу даётся
  до пяти секунд обновлений, затем срабатывает удаление спящего агента.
  Коты, карпы и круглогодичные птицы этим правилом не затрагиваются.
- **Ограниченные кэши:** максимум 420 спрайтов и 600 замеров, включая пустые
  рисунки и ошибки замера. Вытесненные холсты освобождают пиксельную память;
  история прошлых сезонов не сохраняется бесконечно.
- **Сезонные состояния.** Клён горит багрянцем осенью, зимой деревья стоят голыми
  с рекурсивно ветвящейся кроной и шапками снега, лотос раскрывается только днём.

### Строительство

- **Строгая сетка** как в The Sims — и **четверть-тайлы** для микро-декора: мох,
  галька, ландыши, папоротник ставятся с шагом 1/4 клетки.
- **Модульный ландшафт.** Пруд 4×4, заводь 2×2, ручей 1×3, холм 3×3, ложбина.
  Водоёмы получают природный силуэт, перепады высот автоматически сшиваются,
  ступенчатые углы пруда сглаживаются.
- **Многоклеточные объекты:** мостик 1×3, валун 2×2, триада камней 1×3, беседка 2×2.
- **Призрак объекта** под курсором показывает, что и куда встанет, и подсвечивает
  занимаемые клетки — зелёным или красным.

### Интерфейс — исчезающий, из материалов мира

Тёплое дерево, рисовая бумага, шёлковые шнуры. Когда игрок ничего не строит, через
14 секунд интерфейс растворяется и сад остаётся живой картиной. Любое движение
возвращает его. Иконки предметов в каталоге рисуются тем же кодом, что и сад.

### Прогрессия — Вехи Мастерства

Каталог — путь открытий, а не склад. Недоступное не показывается вовсе:
ни вкладок с замками, ни предметов, которые негде поставить. Игрок начинает
с того, что уже стоит в саду, и одного случайного предмета впереди; каждое
строительство (и повторная постройка того же) открывает следующий случайный
предмет из доступных технически. Новое открытие отмечено золотой точкой —
она горит, пока предмет не построен впервые. Вехи не всплывают
карточками поверх сада: свершившееся тихо дописывается в книгу летописи
(раздел «Вехи мастерства»), а вкладки каталога просто появляются:

| Веха                   | Что открывает                                           |
| ---------------------- | ------------------------------------------------------- |
| Выкопали первый пруд   | вкладка **Пруд** — лотосы, кувшинки, мостики, карпы кои |
| Застали в саду вечер   | вкладка **Свет** — фонари, жаровня                      |
| Положили доски веранды | вкладка **Усадьба** — беседка, сёдзи, тории, цукубаи    |
| Приютили кота          | подушки и миски во вкладке **Гости**                    |
| Птица села у кормушки  | вкладка **Гости** — кормушка, поилка                    |

### Жизнь сада — экосистема и летопись

Сад не декорация, а место, где кто-то дышит. Жители приходят сами, когда для
них есть условия — задач и заданий игрок не получает:

- **Лягушки у воды.** Пруд с тенистыми берегами зовёт их; в дождь и по вечерам
  они заметнее, зимой спят в иле. Подошёл кот — лягушка ныряет без всплеска.
- **Стрекозы над прудом.** Летом их до пяти, осенью меньше, в ливень и ночью
  прячутся на камышах и кувшинках. Пара над одним цветком — тихая редкость.
- **Птицы на кормушке.** Кормушка и поилка определяют, кто прилетит: зимой
  гостей больше, летом все у поилки — пьют и купаются с брызгами. Кошки рядом
  нет, иначе стая вспархивает.
- **Второй кот.** Кот, свободная подушка и миска — и однажды вечером гость
  обойдёт усадьбу. Останется ли — решит сам; шубу принесёт свою.
- **Светлячки.** Тёплой тихой ночью над травой и водой зажигаются огни:
  мигают каждый в своём ритме, к рассвету тают. После дождя порой
  вспыхивают разом — это редкая строка летописи, а не награда.
- **Цапля.** Большая птица приходит к большому пруду днём и на заре:
  стоит подолгу, крадётся вдоль берега, бьёт по воде — карпы
  разлетаются веером. Кот подойдёт близко — цапля не спорит, снимается.
- **Олень.** К роще от восьми деревьев на рассвете и в сумерках выходит
  олень: щиплет траву, поднимает голову, слушает. Летом шкура в пятнах,
  осенью — рога, зимой — густая и светлая. Большой роще достанется пара.

- **Летопись сада.** Первые встречи и редкие события ложатся строками на
  бумагу: лягушонок у камня, хор после дождя, зимний стол у кормушки.
  Без цифр и наград — строка с датой и знаком. Открыть можно строкой
  «Летопись сада» в свитке помощи и тихой строкой в созерцании.
  Всплывающие карточки появляются **не чаще раза в три реальные минуты**,
  независимо от часов сада. Из ожидающих событий показывается только последнее;
  все записи и снимки обрабатываются независимо от этой паузы. Карточка видна
  20 секунд; закрытие и смена сада не сокращают интервал. В скрытой вкладке
  новые карточки не показываются, остаток паузы переживает перезагрузку вкладки
  при доступном `sessionStorage`. Обычные ответы интерфейса на действия не задерживаются.
  Проверка таймеров и DOM: `node --import tsx tools/check-chronicle-toast.ts`.

#### Мирные встречи

- **Коты знакомятся и отдыхают рядом.** Два спокойных соседа (в том числе
  домашние, не только гость с хозяином) делают короткий подход, обнюхиваются,
  отступают на удобное расстояние и поджимают лапы. Встреча конечна, затем
  каждый возвращается к своим делам; повтор возможен только после паузы.
- **Птицы уступают поилку.** В чаше одновременно одна птица, другая ждёт на
  отдельном месте кромки. После купания первая отходит и встряхивает крылья,
  а следующая получает воду. Места привязаны к настоящей чаше, её высоте и
  сиду; удаление/перенос поилки, закат, дождь и кот отпускают очередь.
- **Олени приветствуют друг друга.** В достаточно большой роще второй гость
  иногда выходит к той же поляне. Если рядом спокойно, пара ненадолго
  соприкасается носами; испуг и завершение визита всегда прерывают сценку.
- Подходы не пересекают воду, закрытый туман, дома, крупные камни и перепады
  высоты. У каждого участника только один партнёр, удаление участника или
  изменение земли снимает встречу. Состояния временные и не попадают в save.
- Новые строки **«Отдых рядом»**, **«Купание по очереди»** и **«Приветствие
  оленей»** записываются только после состоявшегося эпизода, без наград и
  обязательных потребностей. Подсказки есть на страницах животных в книге.
  `tools/check-animal-company.ts --preview` проверяет настоящую симуляцию,
  30/60/144 FPS, очередность, препятствия, прерывания, события и сохранения.

Сезон и погода важнее статистики: состав и поведение меняются по календарю,
а не по счётчикам. Никто не голодает и не умирает — жители просто приходят
и уходят по своим причинам. Логика приглашений — чистая функция
(`src/world/habitat.ts`), проверена оффлайно (`tools/check-residents.ts`).

### Стартовая страница — выбор усадьбы

На широком экране рядом со свитком находится список сохранённых садов;
на телефоне — компактная страница выбора без скрытого анимированного холста.

- **Войти в конкретный сад:** имя, дата сохранения и число предметов видны
  сразу. Последний открытый сад стоит первым, но вход всегда явный —
  кнопкой его строки, а не кликом по фону или `Esc`.
- **Создать сад:** необязательное имя, вольный или растущий режим либо один
  из шести готовых ландшафтов. Отмена формы не создаёт лишний слот. Первый
  визит не заводит сад автоматически. Переименованный растущий сад открывается
  по своему ID — имя больше не определяет режим.
- **До выбора — тишина:** игровой цикл не обновляет живность, ветер, погоду,
  часы симуляции, вехи и летопись, не рисует сад и не делает автосохранений.
  Сам мир из слота загружается только после выбора. Уход со страницы до входа
  не записывает стартовую заготовку поверх чужого сада. После входа сохраняется
  обычный календарный/офлайн-ритм растущего сада; ожидание не отыгрывается
  ускоренными кадрами.
- **Сохранения бережны:** загрузка использует прежние резервные копии и миграцию
  одиночного сада. Неудачный выбор оставляет меню открытым с объяснением;
  повреждённый слот не заменяется новым автоматически. Названия выводятся текстом.
- **Свиток остаётся нарисован кодом** (`src/ui/startArt.ts`): рисовая бумага,
  энсо, каллиграфия 静かな庭, красная печать, шёлковый шнур и деревянные валики.
  Его свет берётся из настоящих часов, отдельно от часов неоткрытого сада.
  На десктопе декоративная анимация ограничена 30 кадрами/с; выключенные
  плавные движения и `prefers-reduced-motion` оставляют неподвижный свиток.
- После выбора лист отходит, камера мягко приближается; это же явное действие
  разблокирует звук. Все элементы выбора доступны с клавиатуры, фон игры
  до входа недоступен для нажатий и фокуса.
- `npx tsx tools/check-entry.ts` проверяет список, создание, отмену, ошибки,
  имена, миграции и отсутствие перезаписи другого слота.
  `npx tsx tools/check-startup.ts` запускает настоящий вход днём/ночью, на
  десктопе/телефоне и со старыми садами; проверяет полное отсутствие работы
  игрового цикла и записей в хранилище до выбора.

### Растущий сад — второй режим

Вариант при создании новой усадьбы на стартовом экране или в панели садов:
клочок 2×2 посреди бумажного тумана растёт вместе с игроком.

- **Действия приходят временем**: одно действие за десять настоящих минут,
  запас до трёх, старт с трёх; печати запаса висят под карточкой часов. Посадка, постройка, кисть земли, заливка, тропа и перенос
  стоят действия; убрать предмет — бесплатно. Ошибся — не наказан.
- **Сначала призрак, потом предмет**: тап с предметом в руке ставит
  полупрозрачный призрак. ✓ подтверждает — призрак становится объектом и
  тратит действие; ✕ убирает бесплатно. Любое другое действие (смена
  инструмента, мазок, перенос, закрытие каталога, `Esc`) тоже снимает
  призрак, ничего не стоя; движение и масштаб камеры призрак не трогают.
- **Открытия включают кисти**: земля, вода и рельеф тоже открываются по
  одной записи; первый мазок новой кистью гасит её золотую точку. Растущий
  сад начинает путь строго с одного случайного открытия, вольный — с того,
  что уже прожито, плюс одно впереди.
- **Каталог честен**: в растущем саду видно только то, что влезает в
  текущий размер — пруд 3×3 появится в каталоге, когда сад дорастёт до
  него; вкладки и размеры кисти без подходящих предметов прячутся.
- **Рост как награда, не покупка**: за каждые совершённые действия сад
  предлагает вырасти: **1, 1, 2, 3, 4, 5, 6, 7, 8… действий на ступень**.
  После расширения счётчик прогресса обнуляется; это не суммарные пороги. Игрок видит
  четыре зоны-кандидата — туман приподнимается прямо в сцене, показывая
  воду, гривы и рощи, — и выбирает сторону кликом. `Esc` откладывает выбор.
- **Удвоение площади**: 2×2 → 4×2 → 4×4 → 8×4 → 8×8… Открытая земля уже
  рождена целиком: холмы, заводи, рощи и береговая трава, но ни построек,
  ни троп, ни животных — их приведёт игрок.
- **Туман честен**: за границей открытого прямоугольника нельзя сажать,
  строить, лить землю и вести тропы; жители и летопись считают жизнь только
  внутри открытой земли.
- Сад живёт отдельным слотом (`Растущий сад`) рядом с вольными усадьбами:
  переключаться можно в любой момент, оба сохранения независимы.

## Управление

| Клавиша                 | Действие                                         |
| ----------------------- | ------------------------------------------------ |
| Перетащить              | двигать камеру                                   |
| Колесо / щипок          | приблизить, отдалить                             |
| `B`                     | каталог                                          |
| `M`                     | звук сада (есть и в настройках)                  |
| `H`                     | свиток помощи                                    |
| `R`                     | повернуть предмет                                |
| `X` / ПКМ               | убрать предмет                                   |
| `G`                     | сетка                                            |
| `Esc`                   | отложить инструмент · закрыть лист или летопись  |
| Строка «сесть в тишине» | практики и школа дзена (в созерцании и в свитке) |
| Строка «Летопись сада»  | свиток летописи (в созерцании и в свитке помощи) |
| Строка «куда расти?»    | выбор стороны роста в растущем саду              |
| Печати под часами       | запас действий растущего сада                    |
| Панель: «отменить»      | возврат последнего действия (и «повтор» рядом)   |
| Панель: «поворот»       | повернуть предмет (живёт у поворачиваемых)       |
| `✓` / `✕` под призраком | поставить / убрать призрак (растущий сад)        |
| `×` в углу каталога     | быстро закрыть панель строительства              |
| Панель: «мазок/касание» | ставит движение руки или одиночные касания       |

Зажатой кнопкой можно «рисовать» землёй и рассыпать мелочи.
Сад сохраняется в `localStorage` автоматически.
Интерфейс растворяется сам после двадцати секунд покоя: любое касание
или движение мыши возвращает его. Лишних кнопок нет: звук живёт в
настройках, кровля появляется только с домом, а мастерская времени
открывается клавишей T или нажатием на часы.

## Структура

```
src/
  core/        математика изометрии, шум, часы и сезоны
  world/       модель усадьбы, каталог, вехи, среда обитания, летопись, жители
  render/      акварельная кисть, ландшафт, объекты, постройки, погода, сцена
  ui/          исчезающий интерфейс, стартовая страница, летопись, иконки, стили
tools/
  preview.ts        оффлайн-рендер кадра сада в PNG (для разработки, без браузера)
  start-preview.ts  оффлайн-рендер стартовой страницы — свет по часам суток
```

Оффлайн-превью — удобно смотреть сцену и заставку в любом часе и сезоне без браузера:

```bash
npx tsx tools/preview.ts 18.5 autumn закат.png
npx tsx tools/start-preview.ts 6,12,19,23 start   # свиток утром, днём, в закат и ночью
GUESTS=1 npx tsx tools/preview.ts 11 summer гости.png  # кормушка, поилка и камыши для жителей
```

Проверки независимых часов и длительных циклов:

```bash
TZ=Europe/Amsterdam node --max-old-space-size=192 --import tsx tools/check-grow-clock.ts
TZ=Europe/Moscow node --max-old-space-size=192 --import tsx tools/check-grow-clock.ts
node --max-old-space-size=192 --import tsx tools/check-grow-soak.ts
```

Второй тест ускоренно выбирает состояния на протяжении 120 реальных часов по часам сада
(10 сезонных лет, 24 солнечных суток), проверяет удаление девяти сезонных
популяций, вытеснение спрайтов и ограничение пустых замеров. Это модельный
прогон с нативным Canvas, не 120-часовой браузерный тест и не замер FPS телефона.
