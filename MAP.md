# Карта репозитория

Краткая карта: что где лежит и зачем. Обновляется при добавлении новых файлов/модулей.

| Файл | Назначение |
|---|---|
| `Readme.md` | Конституция эксперимента. **Редактирует только человек** — агенты не трогают. |
| `GDD.md` | Game Design Document: концепции, решения, pipeline идей, решения по карточкам хаоса. |
| `CHAOS_CARDS.md` | 36 карточек-твистов, используются по одной, по порядку. |
| `SESSION_LOG.md` | Append-only журнал последних ~10 сессий. |
| `LESSONS.md` | Уроки: секция Критика + находки Творческого директора + процессные заметки. |
| `STATUS.md` | Короткий текущий статус проекта (3–5 строк). |
| `MAP.md` | Этот файл. |
| `HISTORY/` | Сжатые главы истории (`era-N.md`), создаются Летописцем раз в 10 сессий. |
| `ROADMAP.md` | План по сессиям и рамки MLP — **будет создан в сессии 2 (Critic)**. |
| `ARCHITECTURE.md` | Стек и структура — **будет создан в сессии 3 (Coder)**. |
| `ROLE_STATE.md` | Счётчики ролевой ротации и индекс карточек хаоса — **будет создан в сессии 3 (Coder)**. |
| `CHECKLIST.md` | Ручной чек-лист для человека, обновляется только на вехах. |
